# i.datagon — функционал и интерфейс

Актуально для кабинета **v3.0** (paper / sandbox).
Это не индивидуальная инвестиционная рекомендация и не услуга инвестиционного советника.

Связанные документы: [TZ.md](../TZ.md) · [TZ-CABIN.md](../TZ-CABIN.md) · [TZ-ADVISORY.md](../TZ-ADVISORY.md) · [TZ-MODERNIZATION.md](../TZ-MODERNIZATION.md) · [LIVE-READINESS.md](../LIVE-READINESS.md) · [deploy/LOCAL.md](../deploy/LOCAL.md)

## 1. Что это за продукт

**i.datagon** — персональная paper-лаборатория управления капиталом на контуре T-Invest sandbox:

| Слой | Назначение |
|---|---|
| Книга (portfolio / ledger / vault) | Учёт денег и позиций лаборатории |
| Риск-гейты | Лимиты на имя, рукав, день, kill-switch, вселенная, день отчёта |
| Рукава стратегий | Техсигналы (дневки + M15-скальп) → отдельные PnL |
| Фундамент / рекомендации | Скор компаний → кандидаты → очередь на ваше «Принять» |
| Кабина | Операторский UI: смотреть, настраивать, утверждать |

**Не делает:** автоторговлю без approve, приём чужих денег, боевой UI брокера в браузере, лицензионный ИК.

## 2. Возможности (функционал)

### 2.1. Капитал и лимиты

- Целевой **депозит** (торговый кэш): дотягивает баланс до суммы, не уменьшает.
- **Макс. % на одну бумагу** (1–50%): влияет на план размера позиции и risk-gate.
- **Бюджеты рукавов** в % и ₽ (сумма долей = 100%).
- **Сейф прибыли:** 50% зафиксированной прибыли до перекрытия депозита, затем 20%.

### 2.2. Рукава стратегий

| Код | Название | Таймфрейм | Логика |
|---|---|---|---|
| `sma_cross` | Пересечение средних | дневки | SMA 5 / 20 |
| `donchian_breakout` | Пробой Дончиана | дневки | канал 20 дней |
| `rsi_reversion` | RSI-возврат | дневки | RSI(14): ≤30 buy / ≥70 sell |
| `ema_scalp` | EMA-скальп | M15 | EMA 3 / 8, стоп 1.5% |

Дополнительно:

- план капитала: equity → торговый потолок → бюджет рукава → лимит на имя → пример qty;
- paper-бэктест по локальному CSV: next-bar исполнение, комиссия,
  проскальзывание, PnL, просадка, сделки, benchmark и anchored walk-forward OOS;
- evidence score 0–100 раскрывает вклад OOS edge, выборки, просадки,
  расходов, paper-forward и покрытия walk-forward;
- рекомендации весов используют inverse-volatility и correlation penalty,
  сохраняют cash reserve и ограничены floor/cap/step/cooldown;
- admission gates G1–G5 видны через единый отчёт; live остаётся заблокирован;
- paper-forward кампания заранее фиксирует experiment и минимальный период,
  а капитал допускается только после новых наблюдений с положительным excess;
- отсутствие новых forward-наблюдений более 72 часов переводит gate в `stalled`;
- карточка рукава: правила, позиции, лента сигналов.

### 2.3. Фундамент и рекомендации

- Снимки метрик (P/E, P/B, EPS, ROE, free float, дивидендная доходность).
- Прозрачный скор: **value / quality / div → total** + текстовый rationale.
- Топ кандидатов → proposal с рукавом `fund_screener` (без автоордера).
- Локально: «Демо-данные» без брокера; с брокером: refresh / воркер раз в час.

### 2.4. Агенты и очередь решений

- Агенты **только предлагают** (ордер или веса).
- Вы: **Принять** / **Отклонить**.
- Принятие ордера идёт через risk-gate.
- Флаг `AGENTS_ENABLED` по умолчанию выкл. — очередь может быть пустой; proposals из рекомендаций всё равно создаются через API.

### 2.5. Рынок, новости, журнал

- **Вселенная** — периметр тикеров + причины отсева.
- **Правила риска** — kill, лимиты, день отчёта и т.д.
- **Новости / исследования** — внешний контур; сами сделки не открывают.
- **Журнал** — ордера, проводки и единый audit timeline с проверкой hash-chain.

### 2.6. Воркер (фон)

- Пульс (beat) для статуса «воркер жив».
- Снимки equity.
- Закрытие дневных баров → сигналы дневных рукавов.
- M15 → сигналы скальпа (если есть CSV в `CANDLE_M15_DIR`).
- Периодический refresh fundamentals (если задан токен sandbox).

## 3. Интерфейс кабинета

Вход: токен `APP_AUTH_TOKEN` (не токен Тинькоффа).  
Шапка: статус контура, стоп торговли, обновить, обучение.

### 3.1. Меню разделов

| Раздел | URL | Что видите |
|---|---|---|
| **Обзор** | `#/overview` | Центр капитала, PnL/DD/TWR, качество данных, алерты, очередь и attribution |
| **Портфель** | `#/portfolio` | Вкладки: Капитал · Позиции · Сейф · Аллокация · Расхождение |
| **Стратегии** | `#/strategies` | Чеклист, 4 рукава, бюджеты, план капитала, прогон CSV |
| **Компании** | `#/companies` | Таблица фундамента + скор; демо / refresh |
| **Рекомендации** | `#/recommendations` | Карточки кандидатов → «В очередь» |
| **Агенты** | `#/agents` | Очередь proposals: принять / отклонить |
| **Новости** | `#/news` | Лента · Исследования |
| **Рынок** | `#/market` | Вселенная · Правила риска |
| **Журнал** | `#/journal` | Ордера · Проводки · Audit trail |
| **Настройки** | `#/settings` | Депозит, макс. % на бумагу, дисклеймер |
| **Помощь** | `#/help` | Карта, словарь, туры, версия |

На мобиле основные вкладки: Обзор, Портфель, Рекомендации, Компании, Настройки; остальное — в «Ещё».
Внутренние вкладки сохраняются в hash-параметре `?tab=`: ссылку на Позиции,
Исследования, Правила риска или Сквозной журнал можно открыть напрямую и
вернуться к ней после обновления страницы.

### 3.2. Обзор

- Светлая главная с тремя понятными ответами: всё ли в порядке, где деньги и что сделать сейчас.
- Деньги: стоимость счёта, свободный кэш, сейф, зафиксированный и открытый результат, просадка и TWR.
- «Ваше внимание»: срочные события и до трёх решений со ссылкой в Агенты.
- Стратегии: компактное сравнение результатов по рукавам.
- Надёжность: состояние данных, воркера, сверки и готовности G1–G5; технические детали вынесены вниз.

### 3.3. Портфель

- **Капитал** — стоимость счёта, кэш, сейф; ссылка в Настройки для изменения депозита.
- **Позиции** — cost basis, market value, open PnL, mark/source/freshness и вес.
- **Сейф** — накоплено vs депозит, фаза 50%/20%.
- **Аллокация** — веса и капиталы рукавов.
- **Расхождение** — сверка кэша книги с sandbox (только после явного ввода sandbox cash).

### 3.4. Стратегии

Порядок блоков сверху вниз:

1. **Что смотреть** — чеклист (настройки → таблица → бюджеты → план → прогон).
2. **Четыре рукава** — доля, бюджет, PnL; клик → карточка.
3. **Бюджеты** — % и ₽, сохранить.
4. **Как рукав держит портфель** — формула, лимит на имя, пример лота, «секторов нет».
5. **Прогон на истории** — воспроизводимый experiment report: IS/OOS,
   benchmark, расходы, сделки и явный qualification/cash-fallback verdict.

Карточка рукава (`#/strategies/{id}`): PnL, правила, открытые позиции, фильтр сигналов.

### 3.5. Компании

- Таблица: тикер, total/value/quality/div, P/E, P/B, ROE, див., rationale.
- **Демо-данные** — три эмитента без брокера.
- **Обновить с брокера** — `GetAssetFundamentals` (нужен токен на сервере).

### 3.6. Рекомендации

- Дисклеймер «не ИК».
- Карточки топа по скору.
- **В очередь (топ)** → proposals `fund_screener`.
- Ссылки: Компании, Агенты.

### 3.7. Настройки

- Депозит (₽) и макс. на бумагу (%).
- Ссылка на бюджеты рукавов в Стратегиях.
- Юридическая рамка лаборатории.

### 3.8. Общие UI-паттерны

- Русские названия первичны; коды рукавов вторичны.
- Пустые состояния с объяснением, не «молчаливый ноль».
- Загрузка, ошибка и действительно пустой список — разные состояния; временная
  загрузка не подменяется нулями.
- Туры «Обучение» по разделам; сброс туров в Помощи / шапке.
- Kill-switch в шапке и баннере: стоп новых ордеров (позиции сам не закрывает).

## 4. Типовые сценарии

### Настроить капитал

1. `#/settings` → депозит → «Применить».  
2. Задать макс. % на бумагу → «Сохранить лимит».  
3. `#/strategies` → бюджеты рукавов → «Сохранить».

### Посмотреть, сколько акций купит рукав

1. Стратегии → блок «Как рукав держит портфель» / калькулятор «что будет, если выделить сумму».  
2. Либо `GET /allocation/plan`.

### Фундамент → решение человека

1. Компании → «Демо-данные» (или refresh).  
2. Рекомендации → «В очередь».  
3. Агенты → Принять / Отклонить.

### Проверить техсигнал на истории

1. Стратегии → прогон: рукав + тикер CSV.  
2. Смотреть net PnL, max drawdown, расходы, сделки и excess return.

Авторизация: заголовок `X-App-Token: <APP_AUTH_TOKEN>`.

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/status` | Сводка контура + portfolio |
| GET | `/portfolio` | Книга |
| GET | `/capital/summary` | Рыночная оценка, PnL, просадка и качество цен |

| POST/GET | `/backtests`, `/backtests/{id}` | Сохранённый эксперимент с data/config/code hash |
| GET | `/backtests/{id}/trades` | Сделки сохранённого эксперимента |
| POST/GET | `/paper-forward`, `/paper-forward/{id}` | Предзарегистрированный forward-период |
| POST | `/paper-forward/{id}/observations` | Новая strategy/benchmark equity точка |
| GET | `/admission` | Состояние gates G1–G5; live всегда fail-closed |
| GET | `/live/preflight` | Детальные блокеры независимого live-аудита |
| POST | `/orders/{id}/reconcile` | Идемпотентная сверка неоднозначного ордера |

| POST | `/ledger/events` | Типизированные fee/tax/dividend/withdrawal события |

| GET/PUT | `/allocation`, `/allocation/weights` | Веса рукавов |
| GET | `/allocation/plan` | Прозрачный план капитала |
| GET/PUT | `/allocation/risk` | Версионированная risk policy и история изменений |
| GET | `/sleeves`, `/sleeves/{name}` | PnL и сигналы |
| POST | `/desk/backtest` | Прогон CSV |

| POST | `/fundamentals/demo` | Демо-снимки |
| POST | `/fundamentals/refresh` | Синк с брокером |
| GET | `/recommendations` | Топ кандидатов |
| POST | `/recommendations/propose` | Кандидаты → proposals |
| GET/POST | `/proposals*` | Очередь / approve / reject |
| POST | `/kill`, `/unkill` | Стоп торговли |
| GET | `/universe`, `/news`, `/vault`, `/ledger`, `/orders` | Периметр и журнал |

Статика кабинета: `/`, `/cabin.js`, `/cabin.css`, `/tour.js`, `/tour.css`.

## 7. Ограничения текущей версии

- Нет разбора МСФО/e-disclosure и LLM-аналитики «как чат».
- Нет секторов в аллокации — только тикеры вселенной и лимит на имя.
- Рекомендации — скоринг снимка T-Invest fundamentals, не полный research desk.
- Paper-бэктест разделяет прогрев и OOS-окна без торговли на обучающем отрезке;
  сохранение воспроизводимых экспериментов в БД остаётся блоком M406.
- Live-торговля и боевой токен вне кабинета (отдельное решение).

Дальнейший контур (профиль инвестора, разбор своего портфеля, отчётность): см. блок C в [TZ-ADVISORY.md](../TZ-ADVISORY.md).

Обновлённый план точного PnL, доказательного бэктеста, централизованного
risk engine и нового центра капитала: [TZ-MODERNIZATION.md](../TZ-MODERNIZATION.md).
