# Приёмка кабинета — сценарии J1–J9

Источник работ: [TZ-CABIN.md](TZ-CABIN.md) §A3.  
Фиксация этапа 30: [CABIN-FINAL.md](CABIN-FINAL.md) (кабинет **v1**).  
Прогонять **как оператор**, без подсказок разработчика. Один проход = один чеклист.

## Перед стартом

1. Локально подняты API и (по возможности) воркер; в `.env` есть `APP_AUTH_TOKEN`.
2. Откройте кабинет same-origin (как в `deploy/LOCAL.md`).
3. Если всплыл тур — нажмите **Закрыть** или **Esc**. Туры не должны блокировать сценарии; аварийный стоп закрывает тур сам.
4. Чтобы пройти обучение заново позже: **Помощь → Сбросить все туры**.

Отметка: `[x]` = шаг пройден и понятен без внешних пояснений.

## J1 — Контур жив, торговля не в стопе

**Успех:** < 5 сек с любого раздела по шапке.

- [ ] В шапке видны пиллы: Система / Воркер / Торговля / Агенты
- [ ] Пилл «Торговля» читается как «можно выставлять» или «стоп включён»
- [ ] Переход в другой раздел (например Портфель) — пиллы остаются на виду
- [ ] Кнопка «Обновить» обновляет статус; в подвале видно время обновления

## J2 — Где деньги

**Успех:** назвать стоимость счёта / кэш / сейф и фазу сейфа.

- [ ] На **Обзоре** видны стоимость счёта, свободный кэш, сейф (или честный empty, не молчаливый ноль при ошибке)
- [ ] В **Портфель → Капитал** те же суммы с источником
- [ ] Вкладка **Сейф**: депозит, накоплено, **фаза** (50% или 20%), прогресс
- [ ] Есть оговорка, что это paper-книга, не экран брокера

## J3 — Что делают стратегии

**Успех:** сравнить рукава и открыть ленту сигналов одного.

- [ ] **Стратегии**: таблица сравнения с русскими именами рукавов
- [ ] Открывается карточка рукава (клик по строке / «открыть»)
- [ ] В карточке: PnL, «Как устроен», лента сигналов (или честный empty)
- [ ] Фильтры по тикеру / действию работают или ясно пусты

## J4 — Решить по агенту

**Успех:** принять или отклонить proposal и увидеть новый статус.

- [ ] **Агенты**: баннер «включены / выключены» понятен
- [ ] Есть очередь «ждут решения» или честный empty
- [ ] На карточке — человеческое summary; сырьё только под «Подробнее»
- [ ] **Принять** / **Отклонить** → диалог подтверждения → статус меняется (или явный отказ риска)

## J5 — Новость ↔ тикер / research

**Успех:** найти новость, открыть study или честно увидеть empty.

- [ ] **Новости → Лента**: список или empty с next step
- [ ] Фильтр/чип по тикеру сужает ленту (если есть данные)
- [ ] Вкладка **Исследования**: таблица research или empty «ещё не считалось»
- [ ] Disclaimer: новости сами сделки не открывают

## J6 — Понять отказ

**Успех:** в ордере видна русская причина risk gate.

- [ ] **Журнал → Ордера**: таблица или empty
- [ ] У отклонённого ордера причина по-русски (например «Отклонено: включён стоп торговли»), не сырой `killed`
- [ ] На **Рынке → Правила риска** видно, какие правила режут вход (включая стоп)

## J7 — Аварийный стоп

**Успех:** включить/снять стоп только через confirm; статус в шапке.

- [ ] «Стоп торговлю» / «Снять стоп» открывает модалку (без confirm действие не уходит)
- [ ] Esc / «Отмена» отменяет; Enter / «Подтвердить» — выполняет
- [ ] После стопа: баннер + пилл «стоп включён»
- [ ] Если шёл тур — стоп всё равно доступен (тур закрывается)

## J8 — Научиться пользоваться

**Успех:** пройти тур раздела без внешних объяснений.

- [ ] На каждом разделе кнопка **Обучение** запускает тур
- [ ] Есть прогресс «шаг N из M», **Далее / Назад / Закрыть**
- [ ] **Помощь**: карта, словарь (сейф), сброс туров, ограничения продукта
- [ ] После Помощи + тура Обзора можно своими словами объяснить сейф и стоп

## J9 — Доверять цифрам

**Успех:** видна свежесть данных и оговорка paper ≠ брокер.

- [ ] Подвал: «Данные paper-книги…» и время обновления статуса
- [ ] На Портфеле disclaimer про paper vs Тинькофф / брокер
- [ ] При ошибке сети/API блок пишет ошибку, а не «0 ₽ как будто ок»
- [ ] Источник данных указан там, где оператор смотрит деньги (капитал / сейф)
