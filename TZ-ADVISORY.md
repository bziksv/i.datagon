# ТЗ: персональный контур рекомендаций (поверх лаборатории)

Отдельный лист от [TZ.md](TZ.md) 001–156 и [TZ-CABIN.md](TZ-CABIN.md).  
Лаборатория аллокации остаётся скелетом исполнения. Этот лист — **слой смысла**: компании → скор → кандидаты → approve.

**Формула продукта:** профиль / капитал → оценка имён по фундаменту → кандидаты с rationale → «Принять» (уже есть) → paper.

**Юр. рамка v1:** в UI явно «аналитика лаборатории, не индивидуальная инвестиционная рекомендация / не ИК». Лицензия ИК — отдельное решение, не в этом листе.

Правило работ: один пункт = одна итерация.

## Критерий приёмки блока A+B

1. В кабинете есть **Компании** и **Рекомендации**.
2. По снимкам fundamentals виден скор и понятный reason.
3. «В очередь» создаёт paper-план без автоордера и без отправки брокеру.
4. Дисклеймер на экране рекомендаций.
5. Техрукава SMA/Дончиан/RSI/скальп не удалены — вторичный слой исполнения.
